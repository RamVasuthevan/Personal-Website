## Take a Screenshot
- Capture the entire screen: <kbd>⇧</kbd> + <kbd>⌘</kbd> + <kbd>3</kbd>
- Capture a portion of the screen: <kbd>⇧</kbd> + <kbd>⌘</kbd> + <kbd>4</kbd>
- Open screenshot utility: <kbd>⇧</kbd> + <kbd>⌘</kbd> + <kbd>5</kbd>

## Window Tiling
- Right: <kbd>fn</kbd> + <kbd>⌃</kbd> + <kbd>→</kbd>
- Left: <kbd>fn</kbd> + <kbd>⌃</kbd> + <kbd>←</kbd>
- Top: <kbd>fn</kbd> + <kbd>⌃</kbd> + <kbd>↑</kbd>
- Bottom: <kbd>fn</kbd> + <kbd>⌃</kbd> + <kbd>↓</kbd>

See [Window tiling](https://support.apple.com/en-ca/guide/mac-help/mchl9674d0b0/mac)
